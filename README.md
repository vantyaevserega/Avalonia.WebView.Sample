# Avalonia.WebView.Sample

Sample [Avalonia](https://avaloniaui.net/) desktop application hosting a native WebView via
[Avalonia.Controls.WebView](https://www.nuget.org/packages/Avalonia.Controls.WebView) and exchanging messages between C# and JavaScript.

## Requirements

- .NET 10 SDK
- Windows: Microsoft Edge WebView2 Runtime

## Run

```sh
dotnet run --project Source/WebViewSample.Desktop
```

## Stack

- .NET 10
- Avalonia 12.1
- Avalonia.Controls.WebView 12.1
- ReactiveUI.Avalonia
